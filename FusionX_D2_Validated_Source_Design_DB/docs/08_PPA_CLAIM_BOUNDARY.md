# PPA claim boundary

D2 does not claim 18.45 POPS, 1.1 GHz closure, 24 TB/s sustained bandwidth, or
any production power/area number from RTL parameter multiplication.

The integrated reference top instantiates one parameterized tensor engine. The
64x64 default is a functional logical tile, not a proof that a datacenter
replication factor closes timing, power, routing, clocking, and thermal limits.
Product dimensions must be chosen after synthesis and SRAM/multiplier macro
characterization, then confirmed by P&R, STA and EMIR.
